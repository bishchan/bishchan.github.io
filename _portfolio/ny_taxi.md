This [project](https://github.com/bishchan/NYC-Taxi-Data-ELT-pipeline) implements an end-to-end ELT data pipeline using New York City taxi trip data. The pipeline automates data ingestion, stores raw data in Google Cloud Storage, loads the data into BigQuery, transforms and tests the data using dbt, and exposes curated reporting models through Tableau.
